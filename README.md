# Social Media Analytics

> A SQL-driven exploration of social media data, uncovering hidden patterns in user activity, engagement, hashtags, followers, and more.

## About The Project

A group SQL project focused on analysing a social media database through a series of analytical questions. The project explores user behaviour, post engagement, hashtag trends, follower patterns, and other aspects of the platform to extract meaningful insights from the data.

## Key Analysis

- User activity and engagement
- Most-liked posts
- Hashtag usage and engagement
- Follower and influencer patterns
- Inactive and silent users
- Posting activity by time and day
- Country-wise analysis

## Tools Used

**SQL · MySQL · GitHub**

## Project Files

The repository includes the project presentation with SQL queries, analysis, results, and insights.
